# Print Minas — Gestão de Frota

Aplicação para registro de rotas, retornos, fotos do painel, ocorrências e relatórios da frota.

Desenvolvido por **Kaio Barbosa**.

## Estrutura essencial

- `index.html` — interface e carregamento
- `style.css` — visual responsivo
- `js/app.js` — telas e regras de operação
- `js/db.js` — Supabase, armazenamento local e fila offline
- `manifest.webmanifest` e `sw.js` — aplicativo instalável/offline
- `sql/` — migrações do Supabase
